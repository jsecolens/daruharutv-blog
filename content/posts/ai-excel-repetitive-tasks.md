엑셀을 잘한다는 말은 생각보다 범위가 넓습니다. 복잡한 수식을 만드는 사람도 있고, 자료를 보기 좋게 정리하는 사람도 있으며, 여러 파일에서 필요한 숫자를 정확하게 찾아내는 사람도 있습니다.

그런데 실제 업무에서 우리를 지치게 하는 것은 대단히 어려운 계산만이 아닙니다. 파일을 하나씩 열어 복사하고, 날짜 표기를 맞추고, 같은 항목이 두 번 들어갔는지 찾는 일도 상당한 시간을 잡아먹습니다. 분명 하루 종일 일을 했는데, 돌아보면 복사와 붙여넣기를 반복한 것 같은 날도 있지요.

이런 작업은 AI를 활용해볼 만한 좋은 출발점입니다. 거창한 자동화 시스템부터 만들 필요는 없습니다. 자주 반복하는 엑셀 작업 하나를 골라, 원하는 결과를 말로 설명하는 것부터 시작하면 됩니다.

## 먼저, 엑셀을 직접 처리할 수 있는 AI인지 확인하세요

AI에게 엑셀에 관해 질문하는 것과 실제 파일을 읽고 수정하게 하는 것은 다릅니다. 함수 사용법만 설명하는 환경도 있고, 첨부한 파일을 분석해 새로운 엑셀 파일로 돌려주는 환경도 있습니다.

예를 들어 클로드의 공식 안내는 엑셀 파일 생성과 편집, 수식과 그래프를 포함한 결과물 제작을 지원한다고 설명합니다. 다만 사용하는 서비스와 계정에서 파일 첨부·처리 기능이 제공되는지는 먼저 확인해야 합니다. [파일 생성·편집 공식 안내](https://support.claude.com/en/articles/12111783-create-and-edit-files-with-claude)

처음에는 개인정보나 실제 거래 내역 대신, 연습용 자료 열 줄 정도로 시험해보세요. 파일을 첨부한 다음 "처리한 결과를 내려받을 수 있는 엑셀 파일로 만들어주세요"라고 요청하면 됩니다. 답변 속 표만 받는 것과 실제 파일을 받는 것은 사용 편의성에서 차이가 큽니다.

그리고 원본은 별도로 보관하세요. 결과 파일 이름을 '원본파일명_정리본.xlsx'처럼 정해두면 무엇이 바뀌었는지도 비교하기 쉽습니다.

## 1. 여러 파일을 하나로 합치기

월별 실적, 지점별 신청 내역, 담당자별 목록처럼 비슷한 파일을 모으는 일부터 시작해볼 수 있습니다. 파일이 몇 개만 되어도 시트를 열고 닫으며 복사하는 과정이 은근히 번거롭습니다.

하지만 여기서 '합친다'는 말에는 두 가지 의미가 있습니다. 같은 종류의 목록을 아래로 이어 붙일 수도 있고, 고객번호처럼 공통된 번호를 기준으로 다른 파일의 정보를 옆에 붙일 수도 있습니다. 원하는 방식을 구분해 말해주는 것이 좋습니다.

월별 내역을 하나의 긴 목록으로 만들고 싶다면 이렇게 요청해보세요.

> 첨부한 월별 엑셀 파일의 거래 내역을 한 시트에 아래로 이어 붙여주세요. 반복된 제목 행과 소계·총계 행은 거래 목록에서 제외하고, 제외한 행은 별도 시트에 남겨주세요. 각 행이 어느 파일에서 왔는지 알 수 있도록 '원본 파일명' 열을 추가해주세요. 원본은 유지하고 새로운 엑셀 파일로 만들어주세요.

'원본 파일명'은 작은 장치지만 나중에 큰 도움이 됩니다. 이상한 금액을 발견했을 때 어느 자료에서 가져왔는지 바로 찾을 수 있기 때문입니다.

결과를 받았다면 원본별 거래 건수와 통합 후 건수가 맞는지 확인해보세요. 소계 행을 거래처럼 포함하면 같은 금액이 두 번 더해질 수 있으므로, 무엇을 제외했는지 따로 남기게 하는 것이 좋습니다.

## 2. 중복 항목은 바로 지우지 말고 후보부터 표시하기

"중복을 없애주세요"는 간단한 요청처럼 보이지만, 기준이 없으면 위험합니다. 같은 이름이라고 같은 사람은 아니고, 같은 사람이 여러 번 신청한 기록이라고 모두 잘못된 자료도 아니기 때문입니다.

엑셀 자체에도 중복을 표시하거나 제거하는 기능이 있습니다. 공식 도움말 역시 중복 값을 확인하는 것과 삭제하는 것을 구분하고 있습니다. AI를 사용할 때도 이 구분을 그대로 적용하면 좋습니다. [중복 확인·제거 안내](https://support.microsoft.com/en-us/excel/get-started/filter-for-unique-values-or-remove-duplicate-values)

예를 들어 신청번호가 고유한 자료라면 다음처럼 요청할 수 있습니다.

> 신청번호가 같은 행을 중복 후보로 표시해주세요. 같은 신청번호인데 내용이 다른 경우에는 어떤 열이 다른지도 적어주세요. 이름만 같은 행은 중복으로 처리하지 말고, 지금 단계에서는 어떤 행도 삭제하지 마세요.

신청번호가 없다면 이름과 신청일처럼 여러 항목을 함께 볼 수 있습니다. 다만 그것도 완벽한 기준은 아닐 수 있으니 '같은 항목으로 판단할 조건'을 먼저 정해야 합니다.

예를 들어 이름도 날짜도 같은 두 행이 실제로는 서로 다른 신청 건일 수 있습니다. AI가 예쁘게 정리한 표보다 원래 기록의 의미가 우선입니다. 후보를 확인한 뒤 어떤 행을 남길지 결정하는 순서가 실용적입니다.

## 3. 제각각인 날짜와 이름 표기 정리하기

어떤 파일에는 '2026.09.01', 다른 파일에는 '2026-09-01', 또 다른 곳에는 '9월 1일'이라고 적혀 있습니다. 사람은 비슷하게 읽지만 정렬과 집계 과정에서는 문제가 생길 수 있습니다.

회사명이나 품목명도 마찬가지입니다. 앞뒤에 공백이 들어가거나 괄호 표기가 달라 같은 항목이 여러 그룹으로 나뉘는 경우가 있습니다. Microsoft의 자료 정리 안내도 이런 데이터 정리 작업을 다룹니다. [엑셀 자료 정리 안내](https://support.microsoft.com/en-us/excel/top-ten-ways-to-clean-your-data)

이때 중요한 원칙은 '알아보기 좋게 통일하기'와 '원래 뜻을 바꾸기'를 구분하는 것입니다.

> 날짜는 연·월·일이 확인되는 항목만 YYYY-MM-DD 형식으로 통일해주세요. 연도가 없거나 해석이 여러 가지인 날짜는 원문을 유지하고 '확인 필요'로 표시해주세요. 이름의 앞뒤 공백은 제거하되, 서로 다른 명칭을 같은 것으로 합치지는 마세요. 변경 전후를 비교할 수 있는 시트를 추가해주세요.

가령 '03/04'가 3월 4일인지 4월 3일인지는 자료를 만든 방식에 따라 달라질 수 있습니다. AI가 자신 있게 한쪽으로 바꾸었다고 그것이 정답이 되는 것은 아닙니다.

또 하나 자주 놓치는 것이 앞자리 0입니다. 상품코드 '00125'는 계산할 숫자 125와 다릅니다. 전화번호나 우편번호도 마찬가지입니다. 엑셀은 숫자로 해석한 값에서 앞자리 0을 없앨 수 있으므로, 이런 항목은 문자로 유지하도록 요청하는 편이 좋습니다. [앞자리 0과 긴 번호 보존 안내](https://support.microsoft.com/en-gb/excel/keeping-leading-zeros-and-large-numbers)

이미 원본에서 사라진 0은 표시 형식만 바꾼다고 정확히 복구되는 것이 아닙니다. 원래 몇 자리였는지 확인할 근거가 있어야 합니다.

## 4. 월별·항목별 합계와 그래프 만들기

엑셀 파일이 정리되면 다음 질문은 보통 비슷합니다. "어느 달에 가장 많았지?", "어느 항목이 많이 늘었지?", "이걸 한눈에 볼 수 없을까?" 하는 것입니다.

AI에게는 단순히 그래프를 만들어달라고 하기보다 무엇을 묶어서 어떤 숫자를 보여줄지 알려주면 좋습니다.

> 날짜와 항목을 기준으로 월별 지출 합계를 만들어주세요. 취소 건은 제외하고, 환불은 음수 금액으로 반영해주세요. 분류할 수 없는 항목은 '미분류'로 남겨주세요. 월별 합계표와 막대그래프를 만들고, 제외한 건수와 금액도 함께 적어주세요.

이 예시에서 취소와 환불 처리 기준은 요청자가 정한 규칙입니다. 실제 업무에서는 회사나 자료의 기준에 맞게 바꿔야 합니다. 같은 파일이라도 취소 건을 포함하느냐에 따라 합계는 달라집니다.

그래프는 보기 좋게 만들어질수록 믿고 싶어집니다. 그래서 더 기본적인 것을 확인해야 합니다. 금액 단위가 원인지 천 원인지, 빈칸을 0원으로 처리하지 않았는지, '미분류' 금액을 빼놓지 않았는지 살펴보세요.

나중에 자료를 추가할 예정이라면 결과를 고정된 숫자로 받을지, 수식이 포함된 파일로 받을지도 정하면 좋습니다. 수식이 들어 있다고 새 행까지 자동으로 반영된다고 가정하지 말고, 연습용 행 하나를 추가해 실제로 합계가 바뀌는지 확인해보세요.

## 5. 두 파일에서 달라진 내용 찾기

'최종', '최종수정', '진짜최종'이라는 파일 이름을 보며 무엇이 달라졌는지 다시 열어본 적이 있다면 이 작업이 특히 반가울 수 있습니다.

다만 첫 번째 파일의 10번째 줄과 두 번째 파일의 10번째 줄을 그대로 비교하면 안 되는 상황이 많습니다. 중간에 한 줄만 추가되어도 아래의 행 번호가 전부 밀리기 때문입니다.

> 두 파일을 주문번호 기준으로 비교해주세요. 새로 추가된 주문, 사라진 주문, 기존 주문 중 값이 바뀐 항목을 구분해주세요. 변경된 항목은 이전 값과 이후 값을 나란히 표시해주세요. 주문번호가 비어 있거나 중복된 경우에는 자동으로 연결하지 말고 별도 목록으로 남겨주세요.

핵심은 비교할 때 기준으로 삼을 번호입니다. 주문번호, 신청번호, 관리번호처럼 각각의 기록을 구분하는 항목이 있으면 설명하기 쉽습니다.

공통 기준이 없는 파일이라면 AI에게 먼저 "어떤 항목을 기준으로 비교할 수 있는지 제안해달라"고 요청해도 좋습니다. 하지만 이름이 비슷하다는 이유만으로 같은 기록이라고 확정하지 않도록 해야 합니다.

이렇게 만든 변경 목록은 단순히 확인 시간을 줄이는 데서 끝나지 않습니다. 다른 사람에게 "무엇을 수정했는지" 설명할 때도 도움이 됩니다.

## 결과 파일을 받으면 딱 네 가지부터 보세요

처음부터 모든 셀을 검토하려고 하면 다시 부담스러워집니다. 우선 작업 목적에 맞는 기본 항목부터 확인해보세요.

| 확인할 것 | 직접 볼 내용 |
| --- | --- |
| 건수 | 행이 예상보다 늘거나 줄지 않았는지 |
| 합계 | 원본과 결과의 차이를 설명할 수 있는지 |
| 예외 | 빈칸, 중복 번호, 해석이 어려운 날짜가 남아 있는지 |
| 보존 | 상품코드, 전화번호, 원래 수식 등이 의도대로 유지됐는지 |

일부 행을 골라 원본과 직접 대조하는 것도 좋습니다. 일반적인 행뿐 아니라 환불, 빈칸, 긴 번호처럼 실수가 나기 쉬운 행을 포함하면 더 유용합니다. 중요한 제출 자료라면 일부 확인만으로 끝내지 말고 필요한 범위까지 검증해야 합니다.

복잡한 매크로, 외부 파일 연결, 특수 서식이 들어 있는 문서는 단순한 표와 다릅니다. 값을 잘 정리했다고 기존 기능까지 모두 유지됐다고 볼 수 없으므로, 어떤 기능을 반드시 보존해야 하는지 먼저 알려주세요.

회사 자료를 사용할 때는 업로드가 허용된 서비스인지 확인하고, 작업에 필요 없는 개인정보는 제외합니다. 연습 목적이라면 실제 이름과 연락처를 가상의 값으로 바꿔도 충분합니다.

## 결국 엑셀을 배울 필요가 없어지는 걸까요?

저는 모든 함수를 외워야 한다는 부담은 줄어들 수 있지만, 자료를 읽는 능력은 더 중요해진다고 생각합니다. AI는 수식을 만드는 데 도움을 줄 수 있어도 무엇을 합쳐야 하는지, 같은 항목이 무엇인지, 어떤 값을 제외해야 하는지는 업무 맥락이 있어야 판단할 수 있기 때문입니다.

오히려 예전에는 함수가 어려워 시도하지 못했던 작업을 이제는 해볼 수 있게 됩니다. 그러면서 "아, 이 자료에는 비교 기준이 없구나", "날짜가 이렇게 섞이면 문제가 생기는구나"를 실제 결과를 보며 배우게 됩니다.

처음부터 다섯 가지를 한 번에 해볼 필요는 없습니다. 가장 귀찮았던 작업 하나를 고르고, 작은 복사본으로 시작해보세요. 요청 문장과 확인 기준을 함께 저장해두면 다음 달에는 조금 더 수월하게 같은 일을 처리할 수 있습니다.

AI로 엑셀을 잘 쓰는 출발점은 어려운 명령어가 아니라, 내가 원하는 정리 기준을 분명하게 설명하는 데 있습니다.

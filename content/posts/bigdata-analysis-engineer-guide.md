데이터 분야 자격증 시리즈의 네 번째, 빅데이터분석기사입니다. SQLD, ADsP, ADP를 소개해 드렸는데, 이 자격증들이 한국데이터산업진흥원에서 시행하는 국가공인 민간자격인 반면, 빅데이터분석기사는 국가기술자격이라는 점에서 차별화됩니다. 데이터 분석 관련 자격증 중 응시자 수가 가장 많고 취업 시장에서의 인지도도 가장 높은 자격증입니다. 오늘은 빅데이터분석기사의 시험 구성, 필기와 실기의 특징, 합격 전략, 그리고 다른 데이터 자격증과의 관계까지 정리해 드리겠습니다.

## 빅데이터분석기사란?

빅데이터분석기사는 한국데이터산업진흥원에서 시행하는 국가기술자격입니다. 2021년 4월에 첫 시험이 치러진 비교적 신설 자격증이지만, 데이터 분석 분야의 대표 자격증으로 빠르게 자리 잡았습니다. 자격증에는 과학기술정보통신부장관과 국가데이터처장이 기재됩니다.

대용량 데이터를 구축, 탐색, 분석하고 시각화하여 유용한 정보를 도출하고 결과를 예측하는 실무 역량을 검증하는 시험입니다. 정형 데이터뿐 아니라 비정형 데이터를 다루는 능력까지 평가 범위에 포함됩니다.

데이터 분야 자격증 체계에서 빅데이터분석기사의 난이도는 ADsP와 ADP의 중간 수준으로 평가됩니다. ADsP보다는 확실히 어렵지만, ADP의 극악한 실기 난이도에 비하면 접근 가능한 수준입니다.

## 응시자격

빅데이터분석기사는 기사급 국가기술자격이므로 응시자격 요건이 있습니다. 다음 조건 중 하나를 충족해야 합니다.

첫째, 관련 학과 4년제 대학교 졸업자 또는 졸업 예정자입니다.

둘째, 관련 학과 전문대학 졸업자 + 실무경력 요건을 갖춘 경우입니다.

셋째, 동일 또는 유사 직무 분야의 산업기사 자격 취득 후 실무경력 1년 이상인 경우입니다.

넷째, 동일 또는 유사 직무 분야에서 4년 이상의 실무경력이 있으면 학력에 관계없이 응시 가능합니다.

다섯째, 다른 종목의 기사 이상 자격 보유자도 응시할 수 있습니다. 예를 들어 정보처리기사를 이미 취득한 분이라면 별도 경력 없이 바로 응시 가능합니다.

참고로, ADsP 합격만으로는 빅데이터분석기사 응시자격이 주어지지 않습니다. ADsP는 ADP의 응시자격으로 연결되지만, 빅데이터분석기사는 별도의 국가기술자격 체계이기 때문입니다.

## 시험 일정과 접수 방법

빅데이터분석기사는 연 2회 시행됩니다. 2026년에는 상반기(제12회)와 하반기(제13회) 총 2회가 예정되어 있습니다.

원서접수는 데이터자격검정 홈페이지(dataq.or.kr)를 통해 온라인으로 진행됩니다. 접수 시 사이트 접속자가 몰려 서버가 다운되는 일이 빈번하니, 접수 시작 시간에 맞춰 미리 로그인해 두는 것이 좋습니다.

응시 수수료는 필기 17,800원, 실기 40,800원입니다. 시행 지역은 서울, 경기, 인천, 대전, 대구, 부산, 광주, 울산, 강원, 제주 등 전국 10개 지역입니다.

필기시험에 합격하면 합격자 발표일로부터 2년간 실기시험 응시 자격이 유지됩니다.

## 시험 구성 – 필기와 실기

### 필기시험

필기시험은 총 4과목, 객관식 80문항으로 구성됩니다. 시험시간은 120분(2시간)입니다.

1과목: 빅데이터 분석 기획 (약 20문항) – 분석 과제 정의, 분석 마스터플랜 수립, 데이터 분석 방법론, 분석 거버넌스 등을 다룹니다. ADsP의 '데이터 분석 기획' 과목과 범위가 상당 부분 겹치며, 암기 비중이 높은 과목입니다.

2과목: 빅데이터 탐색 (약 20문항) – 데이터 전처리, 탐색적 데이터 분석(EDA), 통계 기법, 데이터 변환 등을 다룹니다. 필기뿐 아니라 실기에서도 핵심이 되는 과목이므로 깊이 있게 공부해야 합니다.

3과목: 빅데이터 모델링 (약 20문항) – 분류, 회귀, 군집 분석, 앙상블, 딥러닝 등 다양한 머신러닝 모델의 원리와 특성을 다룹니다. 비전공자가 가장 어려워하는 과목이지만, 최근에는 기초적인 수준의 문제가 많이 출제되는 편입니다.

4과목: 빅데이터 결과 해석 (약 20문항) – 분석 결과 해석, 시각화, 모델 평가, 분석 결과 활용 등을 다룹니다.

합격 기준은 과목당 100점 만점에 40점 이상(과락 기준), 전체 평균 60점 이상입니다.

### 실기시험

실기시험은 빅데이터분석기사의 가장 큰 특징이자 핵심입니다. 필답형과 작업형이 통합된 형태로 진행되며, 시험시간은 180분(3시간)입니다.

실기는 CBT(Computer Based Test) 방식으로 진행되며, 시험장의 컴퓨터에서 Python 또는 R을 사용하여 실제 데이터 분석을 수행해야 합니다.

실기의 구성은 크게 세 가지 유형으로 나뉩니다.

단답형/서술형 – 데이터 분석 이론, 통계 개념, 용어 등에 대한 필답형 문제입니다.

작업형 제1유형 – 주어진 데이터를 전처리하고 특정 조건에 맞는 결과를 도출하는 코딩 문제입니다. 데이터 조작과 변환 능력을 평가합니다.

작업형 제2유형 – 주어진 데이터셋을 활용하여 머신러닝 모델을 구축하고, 예측 결과를 제출하는 문제입니다. 전처리, 모델 학습, 평가까지의 전 과정을 코드로 작성해야 합니다.

합격 기준은 100점 만점에 60점 이상입니다.

실기시험은 인터넷이 연결된 환경에서 진행되므로, 시험 시작 전 배정받은 컴퓨터의 인터넷 연결 상태를 반드시 확인해야 합니다.

## 합격률과 난이도

빅데이터분석기사의 합격률은 다른 기사급 자격증에 비해 상대적으로 높은 편입니다.

필기시험 합격률은 초기(1~4회)에는 50% 미만이었으나, 5회차 이후로는 약 60% 수준으로 안정되었습니다. 실기시험 합격률은 약 50~60%대를 형성하고 있으며, 최근에는 다소 하락하는 추세입니다. 최종 합격률(필기+실기 모두 통과)은 약 20~30% 수준입니다.

매 회차 응시자 약 6,000명 중 최종 합격자는 약 2,000명 정도로 추정되며, 다른 기사 자격증(전기기사, 정보처리기사 등)에 비하면 비교적 합격 가능성이 높은 시험입니다.

다만 실기시험의 코딩 작업형은 Python이나 R에 대한 실습 경험 없이는 대응이 어렵기 때문에, 프로그래밍 경험이 전혀 없는 비전공자에게는 진입 장벽이 존재합니다.

## 자격증 활용처와 취업 전망

빅데이터분석기사는 국가기술자격이라는 점에서 공기업·공공기관 채용에서 강력한 경쟁력을 갖습니다.

공기업 및 공공기관 채용 시 기사급 자격증 가산점을 받을 수 있으며, 데이터 관련 직무뿐 아니라 IT 직무 전반에서 우대받는 경우가 늘고 있습니다. 정보처리기사와 함께 보유하면 IT 분야 채용에서 더욱 유리합니다.

민간 기업에서도 데이터 분석가, 데이터 엔지니어, AI 개발자, BI 분석가 등의 직무로 취업할 때 경쟁력이 됩니다. 특히 2020년대 들어 데이터 기반 의사결정에 대한 수요가 폭발적으로 늘면서, 빅데이터분석기사의 시장 가치도 함께 상승하고 있습니다.

다른 기사 자격증의 응시자격 확보 용도로도 활용됩니다. 빅데이터분석기사를 취득하면 다른 종목의 기사 시험에 바로 응시할 수 있는 자격이 생기므로, 정보처리기사 등 관련 자격증을 추가 취득하는 데 도움이 됩니다.

한 가지 유의할 점은, 빅데이터분석기사는 국가기술자격이므로 별도의 유효기간이 없고, 한 번 취득하면 평생 유효합니다. 이 점이 SQLD, ADsP, ADP(모두 유효기간 2년 + 보수교육 필요)와의 중요한 차이점입니다.

## 효과적인 공부법

### 필기시험

ADsP를 먼저 공부한 분이라면 필기 준비 기간을 크게 단축할 수 있습니다. 1과목(분석 기획)은 ADsP와 범위가 상당 부분 겹치며, 나머지 과목도 ADsP에서 배운 데이터 분석 기초 이론이 그대로 연결됩니다.

ADsP 합격자 기준으로 필기 준비 기간은 약 1~3주 정도입니다. 처음부터 준비하는 비전공자라면 1~2개월을 권장합니다.

기출문제 반복 학습이 핵심 전략입니다. 최근 3개년 기출문제를 최소 3회 이상 반복 풀이하면서 출제 패턴을 파악하세요. 특히 2과목(빅데이터 탐색)은 실기와 직결되는 내용이므로, 필기 공부 단계에서부터 실기를 의식하며 깊이 있게 학습하는 것이 효율적입니다.

### 실기시험

실기의 핵심은 Python 또는 R 코딩 실습입니다. 어떤 언어를 선택하든, 데이터 전처리부터 모델링까지의 전 과정을 코드로 구현할 수 있어야 합니다.

작업형 제1유형(전처리) 대비로는 pandas(Python) 또는 dplyr(R)을 활용한 데이터 조작, 결측치 처리, 이상치 탐지, 데이터 변환 등을 반복 연습하세요.

작업형 제2유형(모델링) 대비로는 전처리 → 데이터 분할(train/test) → 스케일링 → 모델 학습 → 예측 → 제출의 파이프라인을 자신만의 코딩 템플릿으로 만들어 두는 것이 좋습니다. 로지스틱 회귀, 랜덤 포레스트, XGBoost 등 주요 모델을 능숙하게 다룰 수 있어야 합니다.

코딩이 익숙해진 상태라면 실기 준비 기간은 약 1~3주 정도입니다. 코딩 초보자라면 2~3개월 이상의 실습 기간이 필요합니다.

시험 환경이 일반적인 개인 PC와 다를 수 있으므로, 온라인 코딩 환경(구름IDE 등)에서 연습하는 것도 도움이 됩니다.

## 다른 데이터 자격증과의 관계

이전 포스팅에서 소개한 자격증들과 빅데이터분석기사의 관계를 정리하면 다음과 같습니다.

SQLD는 SQL 쿼리 활용 능력에 특화된 자격증으로, 빅데이터분석기사의 데이터 전처리·탐색 영역과 일부 겹칩니다. SQLD를 먼저 취득하면 데이터 조작의 기초를 다질 수 있습니다.

ADsP는 데이터 분석 이론의 입문 자격으로, 빅데이터분석기사 필기의 기초가 됩니다. ADsP → 빅분기 필기 순서로 공부하면 학습 효율이 높습니다.

ADP는 빅데이터분석기사보다 한 단계 높은 전문가 수준의 자격증입니다. 빅분기의 실기가 작업형 중심이라면, ADP의 실기는 통계 분석과 문서 작성까지 요구하여 난이도가 훨씬 높습니다.

정보처리기사와는 직접적인 과목 겹침은 크지 않지만, 정보처리기사를 보유하면 빅데이터분석기사의 응시자격이 되며, 두 자격증을 함께 보유하면 IT 분야 채용에서 강력한 조합이 됩니다.

가장 많이 추천되는 취득 순서는 ADsP → SQLD → 빅데이터분석기사 → ADP입니다. 각 단계에서 쌓인 이론과 실습 경험이 자연스럽게 다음 단계의 학습으로 이어집니다.

## 데이터 분야 자격증 로드맵 – 시리즈 최종 정리

SQLD, ADsP, ADP, 빅데이터분석기사 네 편에 걸쳐 소개한 데이터 분야 자격증 전체 로드맵을 최종 정리합니다.

입문 단계: ADsP(분석 이론, 필기만, 연 4회) + SQLD(SQL 활용, 필기만, 연 4회) – 응시자격 없음, 유효기간 2년

중급 단계: 빅데이터분석기사(국가기술자격, 필기+실기 코딩, 연 2회) – 기사급 응시자격 필요, 평생 유효

전문가 단계: ADP(데이터분석 전문가, 필기+실기 코딩 4시간, 연 2회) / SQLP(SQL 전문가) – 응시자격 필요, 유효기간 2년

빅데이터분석기사가 다른 데이터 자격증 대비 특히 매력적인 이유는, 국가기술자격이라 평생 유효하고, 공기업 채용에서 기사급 가산점이 적용되며, 실기의 난이도가 ADP보다는 접근 가능한 수준이라는 점입니다.

## 마치며

빅데이터분석기사는 데이터 분석 분야에서 가장 인기 있는 국가기술자격으로, 실무에서 요구하는 데이터 분석 역량을 균형 있게 검증하는 시험입니다. 필기에서는 분석 이론을, 실기에서는 Python 또는 R을 활용한 실제 데이터 분석을 평가하므로, 취득 과정 자체가 실무 역량을 키우는 효과적인 학습 경험이 됩니다.

ADsP나 SQLD로 기초를 다진 뒤 빅데이터분석기사에 도전하는 것이 가장 효율적인 경로이며, 이후 ADP까지 확장하면 데이터 분석 분야의 최고 수준의 전문성을 갖출 수 있습니다.

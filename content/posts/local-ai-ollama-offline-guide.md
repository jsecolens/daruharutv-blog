AI를 사용한다고 하면 보통 사이트에 접속해서 질문을 입력하는 모습을 떠올립니다. 인터넷이 연결되어 있어야 하고, 서비스에 따라 유료 구독도 필요합니다. 그래서 "AI를 내 컴퓨터에 설치해서 인터넷 없이 사용할 수 있다"는 이야기가 조금 낯설게 들릴 수 있습니다.

결론부터 말하면 가능합니다. 다만 온라인에서 쓰던 모든 AI와 기능을 그대로 내려받아 사용하는 것은 아닙니다. 내 컴퓨터에서 실행할 수 있도록 제공되는 모델을 준비하고, 그 모델을 구동할 프로그램과 맞는 사양을 갖추는 방식입니다.

오늘은 설치 명령어를 잔뜩 외우기보다, 로컬 AI가 무엇이고 어떤 사람에게 쓸모가 있는지부터 쉽게 정리해보겠습니다.

## 로컬 AI는 내 컴퓨터에서 답변을 계산하는 방식입니다

여기서 '로컬'은 쉽게 말해 내 기기 안이라는 뜻입니다. 질문을 받아 답변을 만드는 핵심 계산을 외부 서버 대신 내 컴퓨터에서 처리하는 것입니다.

외부 서버에서 실행하는 AI는 온라인 주문에, 로컬 AI는 집에서 재료와 도구를 갖춰 직접 만드는 방식에 비유해볼 수 있습니다. 온라인 주문은 내가 큰 주방을 갖출 필요가 없지만 연결된 서비스에 의존합니다. 집에서 만들려면 준비가 필요하지만 준비한 재료로 직접 작업할 수 있습니다.

이 비유에서 '도구'에 가까운 프로그램이 Ollama, '실제로 사용할 재료와 조리법'에 가까운 것이 AI 모델이라고 생각하면 됩니다. Ollama는 로컬 모델을 실행할 수 있는 프로그램이며, 공식 안내는 macOS·Windows·Linux를 지원한다고 설명합니다.

프로그램만 설치했다고 모델까지 모두 준비된 것은 아닙니다. 실행할 모델도 별도로 내려받아야 합니다. 반대로 모델 파일만 있다고 편리한 대화창이 자동으로 생기는 것도 아니므로 실행 프로그램과 모델을 구분하면 이해하기 쉽습니다.

## 인터넷은 언제 필요하고, 언제 없어도 될까요?

처음에는 프로그램과 모델을 내려받기 위해 보통 인터넷이 필요합니다. 하지만 필요한 파일을 준비한 뒤 로컬 모델로 기본 대화를 하는 과정은 인터넷 없이 진행할 수 있습니다. Ollama도 완전한 오프라인 실행을 활용 방식으로 소개합니다.

대신 작업의 성격을 구분해야 합니다.

| 해보고 싶은 일 | 인터넷 없이 사용할 때 생각할 점 |
| --- | --- |
| 내가 붙여넣은 글 요약하기 | 로컬 모델이 처리할 수 있는 길이와 언어 범위에서 시도 가능 |
| 문장을 다듬거나 아이디어 만들기 | 모델의 성능에 따라 결과 차이가 있음 |
| 컴퓨터에 있는 자료 읽기 | 해당 자료를 읽는 앱·도구가 별도로 필요할 수 있음 |
| 오늘 올라온 뉴스 찾기 | 최신 웹 검색에는 인터넷이 필요 |
| 새로운 모델 내려받기 | 다운로드하거나 다른 경로로 파일을 옮겨 준비해야 함 |
| 외부 서비스에 접속해 업무 처리하기 | 해당 서비스에 연결할 수 있어야 함 |

예를 들어 이미 가지고 있는 회의 메모를 세 줄로 요약하는 일과, 오늘 발표된 공지를 찾아 정리하는 일은 다릅니다. 전자는 제공한 글을 처리하는 작업이고, 후자는 새로운 정보를 가져오는 작업입니다.

인터넷이 없는데 AI가 최신 소식을 그럴듯하게 설명한다면, 실제로 오늘의 자료를 확인했는지부터 생각해봐야 합니다. 자연스럽게 말하는 능력과 지금의 사실을 확인하는 능력은 같은 것이 아닙니다.

## Ollama를 설치하면 무조건 로컬 AI인가요?

꼭 그렇지는 않습니다. 이 부분이 가장 헷갈리기 쉽습니다.

Ollama는 로컬 모델뿐 아니라 클라우드 모델도 지원합니다. 클라우드 모델은 외부에서 실행되며, 모델 자체를 컴퓨터에 내려받지 않고 사용할 수 있습니다. 따라서 같은 프로그램 안에서 대화하더라도 선택한 모델과 연결 방식에 따라 처리 장소가 달라질 수 있습니다.

확인할 것은 바탕화면에 앱이 설치되어 있는지가 아니라, 지금 선택한 모델이 내 컴퓨터에서 실행되고 있는지입니다.

Ollama의 공식 FAQ에는 클라우드 기능을 끄는 로컬 전용 설정도 안내되어 있습니다. 이를 적용하면 Ollama의 클라우드 모델과 웹 검색 기능을 사용할 수 없게 됩니다. 로컬 사용이 목적이라면 이 안내까지 확인해두면 좋습니다.

다만 이 설정은 컴퓨터의 모든 프로그램에 인터넷 차단을 거는 기능은 아닙니다. 다른 대화 앱이나 확장 기능을 연결했다면 그 앱이 어디로 데이터를 보내는지도 별도로 확인해야 합니다.

## 고가의 그래픽카드가 꼭 필요한가요?

무조건 새 그래픽카드부터 살 필요는 없습니다. 먼저 현재 컴퓨터와 실행하려는 모델의 조건을 확인하는 것이 순서입니다.

처음 접한다면 세 가지를 구분해보세요.

| 항목 | 쉽게 이해하면 |
| --- | --- |
| 저장 공간 | 내려받은 모델 파일을 보관할 자리 |
| 메모리(RAM) | 컴퓨터가 실행 중인 작업을 펼쳐놓는 공간 |
| 그래픽 메모리(VRAM) | 그래픽카드가 계산에 사용하는 작업 공간 |

저장 공간이 충분하다고 실행 중 필요한 메모리까지 충분한 것은 아닙니다. 큰 가구를 보관할 창고가 있다고 작은 작업대 위에서 바로 조립할 수 있는 것은 아닌 것과 비슷합니다.

GPU, 즉 그래픽카드를 활용하면 계산에 도움을 받을 수 있지만 운영체제와 카드 종류에 따라 지원 조건이 다릅니다. Ollama 공식 문서는 하드웨어별 지원 목록을 별도로 제공합니다.

일부 모델은 일반 메모리와 CPU를 사용해서도 실행할 수 있지만 응답이 느려질 수 있습니다. 또 긴 문서를 한꺼번에 처리하려면 추가 메모리가 필요할 수 있습니다. 단순히 "몇 GB면 모든 모델이 된다"고 정하기 어려운 이유입니다.

처음에는 현재 컴퓨터에서 실행 가능한 작은 모델로 짧은 한국어 질문을 해보세요. 답변 속도와 품질을 직접 보고 나서 더 큰 모델이 필요한지 판단하면 됩니다. 아직 활용 목적도 정하지 않았는데 장비부터 바꿀 필요는 없다고 생각합니다.

## 처음 해본다면 이 정도 순서면 충분합니다

복잡한 개발 환경을 한꺼번에 갖추기보다 하나의 모델로 대화가 되는지부터 확인해보세요.

1. Ollama 공식 다운로드 페이지에서 운영체제에 맞는 프로그램을 설치합니다.
2. 공식 모델 안내에서 로컬로 실행할 모델과 필요한 조건을 확인합니다.
3. 모델을 내려받고 짧은 질문으로 정상 작동하는지 확인합니다.
4. 클라우드 모델이나 웹 검색을 쓰고 있지 않은지 확인합니다.
5. 준비가 끝난 뒤 인터넷 연결 없이 같은 짧은 작업을 시도해봅니다.

Windows에서는 설치 후 명령 프롬프트나 PowerShell에서 `ollama` 명령을 사용할 수 있습니다. 낯설게 느껴지더라도 처음부터 긴 코드를 작성하는 것은 아닙니다.

공식 시작 문서에 나온 로컬 실행 예시 중 하나는 다음과 같습니다.

```text
ollama run gemma4:e2b
```

이는 해당 모델을 준비하고 대화를 시작하는 명령입니다. 처음 실행할 때 모델이 없다면 다운로드가 진행됩니다. 이 모델 역시 저장 공간과 메모리가 필요하므로, 예시를 그대로 실행하기 전에 공식 안내의 현재 조건을 확인하세요.

첫 질문은 이런 정도면 됩니다.

> 다음 문장을 조금 더 자연스러운 존댓말로 바꿔주세요. 의미는 바꾸지 말아주세요. "내일 회의에 필요한 자료 오늘까지 보내주세요."

어려운 질문으로 성능을 평가하기 전에, 내가 사용할 언어로 대화가 되는지부터 확인하는 것입니다. 그다음 짧은 메모 정리나 문장 분류처럼 결과를 쉽게 판단할 수 있는 작업으로 넓혀보면 됩니다.

## 어떤 일을 맡겨보면 활용도가 있을까요?

로컬 AI의 첫 과제로는 정답을 직접 확인할 수 있고, 최신 검색이 필요 없는 일이 좋습니다. 아래는 모델 성능에 맞춰 시도해볼 수 있는 예시입니다.

짧은 메모를 할 일 목록으로 정리하기. 머릿속에 떠오르는 일을 문장으로 적은 뒤, 준비할 것과 확인할 것을 나눠달라고 요청합니다. 없는 일정이나 담당자를 만들어 넣지 않도록 조건을 붙이면 좋습니다.

반복되는 문장의 말투 통일하기. 안내문이나 답변 초안을 공손한 말투로 바꾸거나 길이를 줄이는 작업입니다. 문장 수를 조금씩 늘려가며 이름이나 날짜가 바뀌지 않는지 확인해보세요.

개인 공부 자료를 질문으로 바꾸기. 내가 정리한 내용을 제공하고 복습 문제를 만들어달라고 할 수 있습니다. 답의 근거를 제공한 글에서 찾도록 하면 모델이 내용을 얼마나 잘 읽었는지 확인하기 쉽습니다.

짧은 코드를 설명받기. 코드 몇 줄을 붙여넣고 각 부분이 무슨 역할인지 쉬운 말로 설명해달라고 요청할 수 있습니다. 다만 모델마다 코딩 능력은 다르므로 실제 실행 결과와 함께 확인해야 합니다.

처음부터 PDF 수백 장을 넣어 완벽한 검색 시스템을 만들려 하지 않아도 됩니다. 파일을 읽는 기능, 긴 자료에서 필요한 부분을 찾는 기능, 답변을 만드는 모델은 각각 준비가 필요할 수 있습니다. AI를 설치한 것만으로 컴퓨터 안의 모든 문서를 자동으로 이해하게 되는 것은 아닙니다.

## 로컬이면 개인정보 걱정이 완전히 사라질까요?

실행 장소를 내가 통제할 수 있다는 점은 로컬 AI의 중요한 장점입니다. Ollama는 로컬 실행 시 사용자의 질문과 데이터를 보지 않는다고 설명하며, 클라우드 사용과 구분합니다.

그렇다고 '로컬'이라는 단어만으로 보안이 완성되는 것은 아닙니다. 대화 기록이 저장되는 위치, 다른 사람이 같은 컴퓨터를 사용하는지, 연결한 앱에 외부 전송 기능이 있는지 등을 함께 살펴봐야 합니다.

예를 들어 답변을 로컬에서 만들었더라도 결과 파일을 자동 동기화 폴더에 저장한다면 별도의 클라우드 저장이 발생할 수 있습니다. 질문을 처리하는 장소와 완성된 파일을 보관하는 장소는 다른 문제입니다.

업무용이라면 프로그램 설치와 자료 반입에 관한 조직의 기준도 따라야 합니다. 개인 PC에서 가능하다는 이유만으로 회사 자료에도 같은 방식을 적용할 수 있는 것은 아닙니다.

## 비용은 없을까요? 성능은 온라인 AI와 같을까요?

로컬 실행만 사용하는 구성에서는 온라인 서비스처럼 질문할 때마다 사용료가 붙지 않는 경우가 많습니다. 하지만 하드웨어, 전기, 저장 공간, 설치와 관리에 드는 시간까지 사라지는 것은 아닙니다. 연결한 앱이나 모델의 이용 조건도 확인해야 합니다.

성능 역시 '로컬인가 아닌가' 하나로 결정되지 않습니다. 어떤 모델을 어느 정도 사양에서, 어떤 작업에 사용하는지가 중요합니다. 가벼운 문장 정리에는 충분해도 복잡한 분석이나 긴 문서 작업에는 아쉬울 수 있습니다.

그러니 첫 평가 기준을 "유료 AI를 전부 대체할 수 있나?"로 잡으면 금방 실망할 수 있습니다. "내가 자주 하는 이 작은 일을 인터넷 없이 처리할 수 있나?"로 시작해보면 훨씬 판단하기 쉽습니다.

로컬 AI를 꼭 모든 사람이 설치해야 한다고 생각하지는 않습니다. 편하게 최신 서비스를 사용하는 것으로 충분한 사람도 있고, 실행 환경을 직접 다뤄보고 싶은 사람도 있을 것입니다.

다만 AI가 어디에서 돌아가고, 내 자료가 어디로 이동하는지 이해하는 경험 자체는 의미가 있습니다. 프로그램을 설치하는 것에서 끝내지 말고 작은 작업 하나를 실제로 마쳐보세요. 그 과정에서 나에게 로컬 AI가 필요한 이유도, 아직 불편한 부분도 구체적으로 보이기 시작할 것입니다.
